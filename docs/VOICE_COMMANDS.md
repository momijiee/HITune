# 语音识别命令词配置

本文档记录 HITune 陪伴闲聊状态树需要烧录到关键词匹配语音模块的有限输入。语音识别模块只返回事件 ID；主控根据 `docs/VOICE_STATE_MACHINE.md` 中的当前状态决定下一跳。

## 表格格式

命令词表使用 `docs/语音交互模块/2.2 命令词播报词协议列表.xlsx` 的原始列结构。闲聊命令推荐统一使用：

`AA 55 00 XX FB`

其中 `XX` 是主控读取到的一字节事件 ID。原始音量命令仍保留 `AA 55 04/05/06/07/08 00 FB`。

| 列名 | 填写要求 |
| --- | --- |
| 语义标签 | 使用事件 ID 的十进制值即可 |
| 命令词 | 纯中文短句，不加标点 |
| 功能类型 | 填写 `命令词` |
| 播报语句 | 建议填“嗯”或留给主控播报，避免模块和 MP3 同时说话 |
| 播报模式 | 填写 `主` |
| 发送协议 | `AA 55 00 XX FB`，音量命令除外 |
| 接收协议 | 与发送协议一致 |

## 音量保留命令

| 事件 ID | 原始命令词 | 协议 | 处理 |
| --- | --- | --- | --- |
| `0x04` | 超大音量 | `AA 55 04 00 FB` | 设置播放器音量 30 |
| `0x05` | 减小音量 | `AA 55 05 00 FB` | 当前音量减 5 |
| `0x06` | 最大音量 | `AA 55 06 00 FB` | 设置播放器音量 30 |
| `0x07` | 中等音量 | `AA 55 07 00 FB` | 设置播放器音量 20 |
| `0x08` | 最小音量 | `AA 55 08 00 FB` | 设置播放器音量 5 |

## 识别策略

- 情绪关键词优先级：难过/想哭 > 生气/烦 > 焦虑/紧张 > 累 > 开心 > 无聊。
- 同一事件可以配置多个命令词，但必须返回相同 ID。
- 开放问题只允许回答上表词汇，不能临时生成新输入。
- 若某状态收到不在接收列表中的事件，进入 `S07_UNKNOWN_REPAIR`，再回 `S02_HOME_MENU`。
- 重复说同一个命令时，主控继续使用 `last_id` 去重；只有语音模块结果回到 `0x00` 后才再次触发。
