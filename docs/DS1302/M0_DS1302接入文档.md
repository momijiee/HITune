# DS1302 接入 MSPM0G3507 文档

## 1. 实际接线

根据 `原理图01.jpeg` 和 `原理图02.jpeg`，时间芯片接口 H4 的 5 个引脚如下：

| H4 引脚 | 原理图网络名 | DS1302 功能 | MSPM0G3507 引脚 |
| --- | --- | --- | --- |
| 1 | CLK | SCLK 时钟 | PA23 |
| 2 | DAT | I/O 双向数据 | PA24 |
| 3 | RST | CE/RST 片选 | PA25 |
| 4 | VCC | 电源 | VCC |
| 5 | GND | 地 | GND |

代码中的对应定义在 `BSP/bsp_ds1302.h`：

```c
#define DS1302_CE_PORT         (GPIOA)
#define DS1302_CE_PIN          (DL_GPIO_PIN_25)
#define DS1302_CE_IOMUX        (IOMUX_PINCM55)

#define DS1302_SCLK_PORT       (GPIOA)
#define DS1302_SCLK_PIN        (DL_GPIO_PIN_23)
#define DS1302_SCLK_IOMUX      (IOMUX_PINCM53)

#define DS1302_IO_PORT         (GPIOA)
#define DS1302_IO_PIN          (DL_GPIO_PIN_24)
#define DS1302_IO_IOMUX        (IOMUX_PINCM54)
```

## 3. 对外接口

时间结构体：

```c
typedef struct {
    uint16_t year;   /* 2000-2099 */
    uint8_t month;   /* 1-12 */
    uint8_t day;     /* 1-31 */
    uint8_t hour;    /* 0-23 */
    uint8_t minute;  /* 0-59 */
    uint8_t second;  /* 0-59 */
    uint8_t weekday; /* 1-7, 用户自定义 */
} DS1302_DateTime_t;
```

状态返回值：

```c
typedef enum {
    DS1302_OK = 0,
    DS1302_ERR_NULL,
    DS1302_ERR_INVALID_TIME,
    DS1302_ERR_CLOCK_HALTED
} DS1302_Status_t;
```

接口函数：

```c
void DS1302_Init(void);
DS1302_Status_t DS1302_GetDateTime(DS1302_DateTime_t *time);
DS1302_Status_t DS1302_SetDateTime(const DS1302_DateTime_t *time);
bool DS1302_IsClockHalted(void);
void DS1302_StartClock(void);
```

## 4. 最小调用方式

在需要读取时间的文件里引入头文件：

```c
#include "bsp_ds1302.h"
```

初始化：

```c
SYSCFG_DL_init();
DS1302_Init();
```

读取当前时间：

```c
DS1302_DateTime_t now;

if(DS1302_GetDateTime(&now) == DS1302_OK)
{
    /* now.year / now.month / now.day
       now.hour / now.minute / now.second */
}
```

## 5. 首次校时

DS1302 第一次上电、电池没电、或者读取返回 `DS1302_ERR_INVALID_TIME` 时，需要写入一次当前时间。

示例：

```c
DS1302_DateTime_t init_time = {
    .year = 2026,
    .month = 6,
    .day = 7,
    .hour = 15,
    .minute = 30,
    .second = 0,
    .weekday = 7
};

DS1302_Init();
DS1302_SetDateTime(&init_time);
```

校时成功后，只要备用电池正常，后续上电直接 `DS1302_GetDateTime()` 即可。

## 6. 当前主程序示例

`gpio_toggle_output.c` 中当前演示逻辑：

```c
DS1302_Init();
if(DS1302_IsClockHalted()) {
    DS1302_StartClock();
}
```

主循环中约每 1 秒读取一次：

```c
if(DS1302_GetDateTime(&now) == DS1302_OK)
{
    uart_debug_send_string("RTC Now: ");
    uart_debug_print_datetime(&now);
    uart_debug_send_string("\r\n");
}
```

输出格式：

```text
RTC Now: 2026-06-07 15:30:00
```

## 7. 实现要点

- DS1302 使用三线串行接口，不是 I2C，也不是 SPI 标准外设。
- 命令字节和数据字节都按 LSB first 传输。
- RTC 寄存器是 BCD 格式，驱动内部已经转换成普通十进制字段。
- `DAT/I/O` 是双向线，写入时配置为输出，读取时关闭输出并配置为输入，避免 M0 和 DS1302 同时驱动总线。
- 当前实现使用 24 小时制；如果检测到 DS1302 处于 12 小时模式，会返回 `DS1302_ERR_INVALID_TIME`。
