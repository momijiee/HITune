# HITune 语音芯片命令词与协议映射表

本文档是给关键词匹配语音识别模块使用的命令词清单。原始模板中的四足机器人动作词已替换为 HITune 桌面陪伴花的有限输入。若需要增加同义词，复制对应行，只修改“命令词”，保持协议不变。

## 协议格式

闲聊命令统一使用：

`AA 55 00 XX FB`

主控读取低字节 `XX` 作为事件 ID。音量命令继续保留模块原始协议，便于现场调试。

## 录入注意

- “播报语句”尽量短，正式回复由主控控制 MP3-TF-16P 播放，避免两路语音重叠。
- 同义词可以共用协议，例如“你好”和“小葵小葵”都返回 `0x20`。
- 如果语音模块仍只能用原始唤醒词“小幻小幻”，可以把它作为 `0x20` 的同义词录入。
- 对话树中的等待状态只接受对应分支的有限词；误识别或无关词由主控转入 `S07_UNKNOWN_REPAIR`。
